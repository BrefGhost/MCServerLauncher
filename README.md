# MC Server Launcher

เปิดเซิร์ฟเวอร์ Minecraft จาก modpack ที่ลงไว้ใน CurseForge ให้เพื่อนต่อเข้ามาเล่นได้ ในคลิ๊กเดียว

## วิธีใช้

โหลด `MCServerLauncher-x.y.z-win64.zip` จากหน้า
[Releases](https://github.com/BrefGhost/MCServerLauncher/releases)
→ แตกไฟล์ → เปิด `MC Server Launcher.exe` ในโฟลเดอร์ที่ได้
→ ติ๊กยอมรับ **Minecraft EULA** ครั้งแรกครั้งเดียว
→ **ลากโฟลเดอร์ modpack มาวางในหน้าต่าง**

เก็บทั้งโฟลเดอร์ไว้ด้วยกัน เพราะโปรแกรมสร้างโฟลเดอร์ `servers/` ที่เก็บโลกไว้ในนั้น

แค่นั้น เซิร์ฟเวอร์จะเริ่มเองและที่อยู่สำหรับส่งให้เพื่อนจะขึ้นมาเอง
(วัดจริง: ลากจนเพื่อนต่อได้ 94 วินาที)

รองรับโฟลเดอร์จาก CurseForge, Modrinth และ MultiMC/Prism
จะลากแพ็คเดียวหรือโฟลเดอร์ที่เก็บหลายแพ็คก็ได้ ถ้าไม่อยากลากก็เลือกจากรายการ
(โปรแกรมสแกน `%USERPROFILE%\curseforge\minecraft\Instances` ให้เองอยู่แล้ว)
หรือกดที่ช่องลากเพื่อเปิดหน้าต่างเลือกโฟลเดอร์

### ครั้งแรกเท่านั้น: อนุมัติ playit.gg

รอบแรกโปรแกรมจะเปิดหน้าเว็บ playit.gg ให้กดยืนยันเครื่องนี้ — สมัคร/ล็อกอินแล้วกดอนุมัติ
จบแค่นั้น หลังจากนั้นโปรแกรมสร้าง tunnel และอ่านที่อยู่สาธารณะให้เองผ่าน API ของ playit

## โปรแกรมทำอะไรให้บ้าง

**โปรแกรมไม่ตัดสินว่าม็อดตัวไหนควรอยู่บนเซิร์ฟเวอร์** — ใส่ทุกตัวไปก่อนเสมอ
แล้วเอาออกเฉพาะตัวที่ Forge/NeoForge เขียนชื่อมาเองใน log ว่าโหลดไม่ได้
(`invalid dist DEDICATED_SERVER`) ซึ่งเป็นคำตัดสินของตัวเกม ไม่ใช่การเดา
จึงใช้ได้กับม็อดทุกตัวทุกเวอร์ชันโดยไม่ต้องมีรายชื่ออะไรเลย

วัดจริงกับ HardRock TerraFirmaCraft (327 ม็อด): เซิร์ฟเวอร์ปฏิเสธแค่ **2 ตัว**
(`oculus`, `darkness`) เปิดขึ้นในรอบที่ 2 รวม 2 นาที 55 วินาที
ระบบเก่าที่ใช้รายชื่อคัดออกไป 26 ตัว — เกินความจำเป็น 24 ตัว

**ถ้า modpack มี server pack ทางการ ใช้อันนั้นแทน** เพราะไม่ต้องเปิดซ้ำเลยสักรอบ
CurseForge เขียน ID ของไฟล์นั้นไว้ใน `minecraftinstance.json` ตอนติดตั้งแพ็คอยู่แล้ว

| ขั้นตอน | รายละเอียด |
|---|---|
| ใช้ server pack ทางการ | โหลดจาก CurseForge (281 MB – 1 GB ครั้งเดียวต่อเวอร์ชันของแพ็ค) แล้วแตกไฟล์ทับ ลบ zip ทิ้งหลังเสร็จ |
| หา Java | เลือกเวอร์ชันให้ตรงกับ Minecraft (1.20.x ใช้ Java 17, 1.21+ ใช้ Java 21) จาก Java ที่ CurseForge ลงไว้ให้อยู่แล้ว |
| ติดตั้งเซิร์ฟเวอร์ | โหลดตัวติดตั้ง Forge/NeoForge เวอร์ชันที่ตรงกับ modpack จากเซิร์ฟเวอร์ทางการ แล้วสั่ง `--installServer` |
| คัดลอกม็อด | เชื่อมไฟล์ม็อดแบบ hard link (แพ็ค 1.6 GB ใช้เวลาไม่ถึงวินาที และไม่กินพื้นที่เพิ่ม) |
| คัดลอกเนื้อหาแพ็ค | คัดลอก**ทุกโฟลเดอร์** ยกเว้นที่รู้ว่าเป็นของฝั่งผู้เล่น/ขยะ — แพ็คตั้งชื่อโฟลเดอร์เองได้ไม่จำกัด (SkyFactory ใช้ `thingpacks/`) |
| ใส่ม็อดครบทุกตัว | ไม่คัดอะไรออกล่วงหน้า — การถอดม็อดที่ฝั่งเกมมีคือต้นเหตุของ `mismatched mod channel list` |
| เอาออกเฉพาะที่เซิร์ฟเวอร์ปฏิเสธ | อ่านชื่อจาก log ของ Forge/NeoForge เอง ปิดทุกตัวที่ถูกระบุพร้อมกันในรอบเดียว แล้วลองใหม่ |
| เปิดให้ต่อจากข้างนอก | ใช้ playit.gg เจาะออกจากเน็ตบ้านโดยไม่ต้องตั้งค่า router |
| ปิดอย่างปลอดภัย | สั่ง `stop` ให้เซิร์ฟเวอร์เซฟโลกก่อนเสมอ |
| ปลดล็อกตัวกรองที่บล็อก tunnel | ม็อด Connectivity ที่แพ็คใหญ่ ๆ ติดมาด้วย จะบล็อก IP ของ playit ทำให้ผู้เล่นค้างที่หน้า Logging in — โปรแกรมปิดตัวกรองนั้นให้ |

## เรื่องที่ควรรู้

**ม็อดภาพบางตัวต้องอยู่บนเซิร์ฟเวอร์ด้วย** — Forge/NeoForge เทียบรายการ network channel ตอนผู้เล่นกดเข้า
ถ้าเซิร์ฟไม่มีม็อดที่ฝั่งเกมจดช่องไว้ ทุกคนจะโดนเด้งด้วย `Connection closed - mismatched mod channel list`
โปรแกรมเลยเปิดไฟล์ `.class` ในทุก jar ที่กำลังจะถอด ดูว่ามันอ้างถึงคลาสเครือข่ายของ Forge/NeoForge หรือไม่
ถ้าอ้าง = เก็บไว้บนเซิร์ฟเวอร์ (ยกเว้นตัวม็อดประกาศ `clientSideOnly=true` เอง ซึ่งเชื่อได้เลย)
ผลสแกนเก็บแคชไว้ที่ `data/network-channels.json`

**ทำไมถึงไม่คัดม็อดล่วงหน้า** — เพราะต้องรู้จักม็อดทุกตัวบนโลก ซึ่งเป็นไปไม่ได้
และการคัดผิดสร้างปัญหาเองสองแบบ: ถอดม็อดที่ฝั่งเกมมี → ผู้เล่นโดนเด้งด้วย
`mismatched mod channel list` (เคสม็อด Wakes) และถอดม็อดที่ตัวอื่นต้องพึ่ง → เซิร์ฟพัง (เคส GuideME)
เซิร์ฟเวอร์ปฏิเสธม็อดจริงแค่ไม่กี่ตัว และมันบอกชื่อมาเองอยู่แล้ว

**คัดลอกโฟลเดอร์แบบ denylist ไม่ใช่ allowlist** — modpack เก็บเนื้อหาไว้ในโฟลเดอร์ชื่ออะไรก็ได้
(`thingpacks`, `skyblockbuilder`, `quests_structures`, `trees`, `moddata` — เจอมาแล้วทั้งนั้น)
โปรแกรมเลยคัดลอกทุกโฟลเดอร์ แล้วข้ามเฉพาะรายชื่อที่รู้ว่าไม่เกี่ยวกับเซิร์ฟเวอร์
(`resourcepacks`, `saves`, `logs`, `screenshots`, โฟลเดอร์ที่ขึ้นต้นด้วยจุด ฯลฯ)
**ลืมคัดลอก = พังแบบหาสาเหตุไม่เจอ / คัดลอกเกิน = แค่เปลืองดิสก์**
และการกรองชื่อจะทำเฉพาะชั้นบนสุดเท่านั้น เพราะโฟลเดอร์ชื่อ `patchouli_books` หรือ `journeymap`
ที่ซ้อนอยู่ข้างใน `global_packs/` หรือ `config/` เป็นไฟล์ที่แพ็คแถมมาจริง ๆ

**การเปิดครั้งแรกของแต่ละแพ็คจะเปิด–ปิดซ้ำ 2–3 รอบ** (รอบละประมาณ 1 นาทีในแพ็คใหญ่)
เพราะเซิร์ฟเวอร์ต้องบอกเองว่ารับม็อดตัวไหนไม่ได้ รอบต่อ ๆ ไปโปรแกรมจำไว้แล้วเปิดรอบเดียวจบ

**ที่อยู่สาธารณะดึงมาจาก API ของ playit ไม่ใช่จากหน้าจอ agent** — ตัว agent ไม่พิมพ์ที่อยู่ออกมา
และคำสั่ง `tunnels list` ของ 0.17.1 ตอบ `NotImplemented` แต่ API ที่ agent เองใช้คุยบอกได้:
`POST https://api.playit.gg/agents/rundata` พร้อมหัวข้อ `Authorization: Agent-Key <secret>`
คืนรายการ tunnel ทั้งหมดพร้อม `assigned_domain` และพอร์ต ถ้ายังไม่มี tunnel โปรแกรมจะสร้างให้เอง
ผ่าน `POST /tunnels/create`

**ม็อด Connectivity บล็อกผู้เล่นที่มาทาง tunnel** — ม็อดนี้มีตัวกรอง traffic ที่ยอมรับเฉพาะ IP
ในรายการอนุญาต ซึ่งว่างเปล่าโดยค่าเริ่มต้น เวลาต่อผ่าน playit ผู้เล่นทุกคนจะเข้ามาจาก IP ปลอมในช่วง 127.x
ที่ tunnel สร้างขึ้น ตัวกรองจึงหยุดการเชื่อมต่อไว้เงียบ ๆ จนฝั่งเกมยอมแพ้ — ผู้เล่นเห็นแค่ "Logging in..."
ค้างอยู่ และเซิร์ฟเวอร์ไม่เขียนอะไรลง log เลย

ใส่ IP ทีละตัวไม่ได้ผลเพราะม็อดเทียบแบบตรงตัวเป๊ะ และ IP ปลอมนั้นต่างกันไปในผู้เล่นแต่ละคน
โปรแกรมจึงปิดตัวกรองนั้นให้เมื่อเปิดใช้ tunnel ซึ่งทำให้เซิร์ฟเวอร์กลับไปทำงานเหมือนตอนไม่มีม็อดนี้
(สำรองไฟล์เดิมไว้เป็น `connectivity.json.bak`)

วัดจริงกับ HardRock: ก่อนแก้ผู้เล่นค้างเกิน 60 วินาทีแล้วหลุด หลังแก้เข้าได้ใน 2 วินาที

**ถ้าบัญชี playit หลุด โปรแกรมเชื่อมใหม่ให้เอง** — กุญแจในเครื่องใช้ไม่ได้เมื่อ agent ถูกลบ
บนเว็บหรือถูกรีเซ็ต ตัว agent จะหยุดถามว่า `Invalid secret, do you want to reset (Y/n)?`
บน stdin ที่ไม่มีใครตอบได้ แล้วค้างอยู่ตรงนั้น โปรแกรมจึงตรวจกุญแจกับ API ก่อนเริ่ม agent ทุกครั้ง
ถ้าใช้ไม่ได้ก็ทิ้งแล้วขอเชื่อมใหม่ทันที และมีปุ่ม **เชื่อมบัญชี playit.gg** ให้กดเองได้ตลอด

**traffic ทั้งหมดวิ่งผ่านเซิร์ฟเวอร์ของ playit** — เป็นบริการฟรี แต่ก็หมายความว่าไม่ได้ต่อตรงถึงเครื่องคุณ

**เซิร์ฟเวอร์กับเกมต้องใช้ modpack เวอร์ชันเดียวกัน** — ถ้าอัปเดต modpack ใน CurseForge
ให้กดเริ่มเซิร์ฟเวอร์ใหม่ โปรแกรมจะซิงก์ม็อดให้ตรงกันเอง

## โครงสร้างไฟล์

```
MCServerLauncher/
├── เปิดโปรแกรม.bat          ← ดับเบิลคลิกอันนี้
├── MCServerLauncher.pyw     หน้าต่างโปรแกรม
├── run_headless.py          รันจาก command line (ไม่มีหน้าต่าง)
├── vendor/                  tkdnd สำหรับลากไฟล์ (ฝังมาให้ ไม่ต้องลงเพิ่ม)
├── launcher/
│   ├── dnd.py               รับไฟล์ที่ลากมาวาง
│   ├── instances.py         สแกน modpack
│   ├── javafinder.py        หา Java ที่ถูกเวอร์ชัน
│   ├── installer.py         ติดตั้ง Forge / NeoForge server
│   ├── sync.py              คัดลอกม็อดและค่าตั้ง
│   ├── clientmods.py        คัดม็อดฝั่งผู้เล่น
│   ├── autoheal.py          หาม็อดต้นเหตุจาก log
│   ├── server.py            คุมโปรเซสเซิร์ฟเวอร์
│   ├── serverpack.py        โหลด server pack ทางการจาก CurseForge
│   ├── tunnel.py            playit.gg
│   ├── session.py           ร้อยทุกขั้นตอนเข้าด้วยกัน
│   └── data/
│       ├── clientside_mods.txt    รายชื่อม็อดฝั่งผู้เล่น (จาก ServerPackCreator)
│       └── clientside_extra.txt   รายชื่อที่โปรแกรมเรียนรู้เพิ่มเอง
├── servers/<ชื่อแพ็ค>/       เซิร์ฟเวอร์จริง โลกอยู่ในนี้
├── cache/                   ตัวติดตั้งและ playit ที่โหลดมา
└── data/                    ค่าตั้งและสถานะ
```

โฟลเดอร์ 4 อันล่างสร้างข้างไฟล์ `.exe` — **ยกเว้น**เมื่อเปิด `.exe` จากโฟลเดอร์ที่เป็นของผู้ใช้
(`Downloads`, `Desktop`, `Documents`, ราก drive, `Program Files`) กรณีนั้นจะไปสร้างไว้ที่
`Documents\MC Server Launcher` แทน เพราะเซิร์ฟเวอร์กินพื้นที่หลาย GB และไม่ควรไปกอง
ปนกับไฟล์ส่วนตัว โปรแกรมแสดงตำแหน่งที่ใช้จริงไว้ใต้หน้าต่าง console กดที่ข้อความเพื่อเปิดโฟลเดอร์ได้

## รันจาก command line

```
python run_headless.py --list
python run_headless.py "Contained Opolis" --ram 8 --accept-eula
python run_headless.py "Better MC" --prepare-only
```

## ถ้าเข้าเซิร์ฟไม่ได้ ขึ้นว่า "mismatched mod channel list"

หน้าจอเกมจะบอกชื่อม็อดที่เซิร์ฟเวอร์ขาด (เช่น `Wakes`)

1. พิมพ์ชื่อนั้นลงช่อง **ม็อดที่เซิร์ฟเวอร์ขาด** ในโปรแกรม แล้วกด **เพิ่ม**
2. กดหยุดแล้วเริ่มเซิร์ฟเวอร์ใหม่

โปรแกรมรับได้ทั้งชื่อที่หน้าจอโชว์ (`Wakes`), mod id (`wakes`) และชื่อไฟล์
(`wakes-1.20.1-Forge-1.0.9.jar`) ใส่หลายตัวได้โดยคั่นด้วยจุลภาค
ม็อดที่เพิ่มแบบนี้จะถูกเก็บไว้ตลอด ไม่โดนคัดออกอีก

ปกติควรเจอกรณีนี้น้อยมาก เพราะโปรแกรมตรวจ network channel ให้อยู่แล้ว

## ถ้าเซิร์ฟเวอร์ยังเปิดไม่ขึ้น

1. ดูข้อความในหน้าต่าง console บรรทัดที่ขึ้นต้นด้วย `[วิเคราะห์]` และ `[แก้ไข]`
2. เปิดไฟล์ `servers/<ชื่อแพ็ค>/logs/latest.log`
3. ม็อดที่ถูกปิดไปจะอยู่ในโฟลเดอร์ `servers/<ชื่อแพ็ค>/mods-disabled/`
3. บันทึกของตัวโปรแกรมเองอยู่ที่ `logs/launcher-<ชื่อแพ็ค>.log`
4. กดปุ่ม **ล้างม็อดที่ถูกปิดอัตโนมัติ** ถ้าอยากเริ่มคัดใหม่ทั้งหมด

## ทำไม Windows ขึ้นเตือน "Windows protected your PC"

Microsoft Defender SmartScreen เตือนไฟล์ `.exe` ที่ **ยังไม่มีลายเซ็นดิจิทัล** และ
**ยังไม่มีคนโหลดไปใช้มากพอ** — ไม่เกี่ยวกับว่าโปรแกรมมีอะไรอันตรายอยู่ข้างใน
กด **More info → Run anyway** ครั้งเดียว Windows จะจำไว้และไม่ถามอีก

แก้จากฝั่งโค้ดไม่ได้ ทางเดียวที่ทำให้หายจริงคือ

| วิธี | ราคา | ผล |
|---|---|---|
| ซื้อใบรับรอง Code Signing แบบ EV | ~10,000–20,000 บาท/ปี | หายทันที |
| ซื้อใบรับรองแบบ OV | ~5,000–12,000 บาท/ปี | ยังเตือนอยู่พักหนึ่งจนกว่าจะมีคนโหลดพอ |
| ส่งไฟล์ให้ Microsoft ตรวจ | ฟรี | ช่วยได้บ้าง ไม่รับประกัน |
